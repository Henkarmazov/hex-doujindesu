# Doujindesu API

JSON-only serverless API for Vercel.

## Deploy
1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Deploy. No frontend is needed.

## Routes
- `/`
- `/home`
- `/schedule`
- `/ongoing/page/1`
- `/completed/page/1`
- `/genres`
- `/genres/example/page/1`
- `/search/naruto`
- `/anime/slug`
- `/episode/id`
- `/anime/slug/chapters/page/1`
